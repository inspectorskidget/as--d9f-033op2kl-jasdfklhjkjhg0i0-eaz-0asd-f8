Icons are inline SVGs — supported types: discord, github, x, telegram, youtube, tiktok, instagram, spotify, twitch, steam, email, globe, link.
Scripts show up in the Scripts window (notepad icon on the desktop). Date is auto-filled when you add.
Repos show up in the Repos window (github icon). Clicking one opens the URL.
Friends show up in the Friends window. Clicking a row copies the Discord id — keep these to close friends you're ok sharing IDs of.
Shown by the Terminal's neofetch command. Keep it safe: no serials, no MACs, no IPs.
Push runs: git add -A && git commit && git push. Needs a git remote set on this repo (git remote add origin https://github.com/you/rezi.lol.git) and your git identity configured. GitHub Pages rebuilds automatically after the push.
